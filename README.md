# AuroraPriceBot 💱

ربات تلگرام قیمت لحظه‌ای **ارز، طلا، سکه و رمزارز** — دقیقاً مثل @CoinPJbot ولی **مال خودت**.

## ✨ قابلیت‌ها

- 💵 دلار، یورو، پوند (بازار تهران)
- 🥇 طلا ۱۸/۲۴ عیار، سکه امامی، بهار آزادی، نیم‌سکه، ربع‌سکه، گرمی
- 🪙 تتر بازار داخلی (ریالی)
- 🌐 رمزارزها — بیت‌کوین، اتریوم، سولانا، تون و ۵۰۰+ ارز دیگه (از Binance)
- 🚀 کش ۶۰ ثانیه‌ای → بدون rate-limit
- 💯 کاملاً رایگان، بدون کلید API

## 📦 اجرا

```bash
pip install -r requirements.txt
BOT_TOKEN=توکن_ربات python bot.py
```

## 🚂 دپلوی روی Railway

1. ریپو رو به Railway وصل کن
2. متغیر `BOT_TOKEN` رو از [@BotFather](https://t.me/BotFather) ست کن
3. Start Command: `python bot.py`

## 📖 دستورات

| دستور | کار |
|---|---|
| `/start` | شروع + راهنما |
| `/iran` | قیمت‌های بازار ایران (دلار، طلا، سکه) |
| `/crypto` | رمزارزهای معروف دلاری |
| `/price BTC` | قیمت یک ارز خاص |
| `/all` | همه باهم |
